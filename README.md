**Sayap Nusantara** — a complete 3D flight game that runs offline in a desktop browser. Fly a little twin-engine aircraft over the island of Nusaria: take off from runway 27, thread golden rings, watch your fuel, and bring her home for a clean landing. Three missions (a calm green valley, a mountain sunset, and a storm over the Blue Lake), a chase-view aircraft with lit instruments, and a full HUD: airspeed, altitude, heading compass, attitude indicator, throttle, fuel, rings and score. Keyboard and mouse, no build step, no network — every pixel and sound is generated by the game's own code.

## Run it

```sh
python3 -m http.server --directory game 8080
# open http://localhost:8080 in desktop Chrome
```

Or serve `game/` with any static HTTP server and open `index.html`.

## Controls

- **W / ↑** climb · **S / ↓** descend · **A D / ← →** bank and turn
- **Shift / +** throttle up · **Ctrl / -** throttle down
- **Mouse** steer (move to bank), wheel = throttle
- **G** landing gear · **P** pause · **R** restart mission · **M** menu
